# Catalogue of the ConEx 1.1 → 1.2 Fixes, Recovered from the 1997 Updater

**Yodacon Project Lab Report LR-2026-02** · docs/lab-reports · 2026-08-27
**P. Richeson** (Yodacon project) with Claude (Anthropic) as extraction tooling

---

**Abstract** — The `ConEx12u` updater (1997) is a pair of self-applying
Macintosh patch applications generated by ResCompare 5.0. We recover its
complete patch directory: 15 resource-level changes for the plugin and a
44-item revision of the readme. Every post-patch size matches the mirrored
full *ConEx 1.2* release exactly, proving the full download is the updater's
output state and yielding an authoritative catalogue of what 1.2 fixed:
three hyperspace-link rewires that connect the ConEx home system to the map,
a mission-text destination correction, a rebalanced Regional Map outfit, the
removal of a "Hawk Fighter Bay" weapon, a six-image redraw of the Dart at
new 80×80 sprite dimensions, and an added apology string for a landing bug.
This is Phase 3, item 1 of `backlog.md`.

---

## I. Source and provenance

`ConEx12u.sit.hqx` was recovered from the Internet Archive's
*EscapeVelocityPluginCollection* (`EV.zip` → `EV/Plugins/ConEx12u.sit.hqx`,
mirrored locally in `vendorignored/`), alongside the archive site's 1999
description texts. The chain unpacks as:

    ConEx12u.sit.hqx            BinHex 4.0    sha256 733635f8… (full digests in PROVENANCE.md)
    └─ ConEx 1.2 Patches.sit    StuffIt 5, Arsenic
       ├─ ConEx Readme 1.2 patch   1997-11-28 20:18   APPL/ZAPS, 64,360 B rsrc
       └─ ConEx1.2 patch           1997-11-28 20:54   APPL/ZAPS, 165,980 B rsrc
       (folder                     1997-11-28 20:55)

These timestamps extend the release-evening timeline from LR-2026-01: plugin
saved 20:05, readme 20:15, readme patch built 20:18, plugin patch built
20:54, patch folder stuffed 20:55. The whole 1.2 release — plugin, readme,
and both updater patches — was produced in under an hour on the Friday after
Thanksgiving 1997.

## II. The patch format

Both files are self-applying patchers built by **ResCompare 5.0**
("A resource patching utility … © 1996 by Michael Hecht", per their `vers`
resources; creator code `ZAPS`). The patch data lives in four resource
types, whose layout we recovered by inspection
(`vendor/paulricheson/tools/zap_catalogue.py`):

- **`ZAP#`** — the patch directory. `count:u16`, then per entry:
  `flags:u16, verb:u16, type:4s, id:s16`, a *new* triplet
  `(attrs:u16, size:u32, check:u32)`, an *old* triplet of the same shape,
  and a Pascal name padded to even total length. Verb `0x03xx` replaces a
  resource; `0x0101` marks one that exists only in the old file (removed).
  The directory resource's own name (`ConEx1.1`) names the file to patch.
- **`ZAP `** — the new bytes for each change, one resource per directory
  entry, ids from 1000 in entry order.
- **`ZIS#` / `ZIL#`** — item lists (16-bit and 32-bit variants) giving the
  offsets and lengths where those bytes apply. For single-item patches the
  observed shape is `[0, itemCount, (len, 1, offset)…, 0]`; for
  size-changing edits, `(offset, oldLen, newLen)`.
- The 32-bit `check` values use a ResCompare-internal checksum we did not
  identify (not CRC-32/CCITT/Adler/summation in common variants); size
  agreement across all 15 entries stands in for it below.

## III. The catalogue

`zap_catalogue.py` output, verified against the mirrored full 1.2 plugin
(right column): every replaced resource matches the patch's post-state size,
and the removed resource is absent. **The full ConEx 1.2 download is
byte-consistent with 1.1 + this updater** — the two 1999 distributions agree.

The readme patch (same format, target `ConEx Readme`, type `APPL/Dk@P`,
"^FILE ^VERS backup") carries 44 `ZAP` items revising the DOCMaker chapters
and pictures; it was not catalogued item-by-item.

## IV. Findings for the Phase 3 restoration

1. **The 1.2 story is: connect the home system and polish the Dart.** Three
   of 1.1's systems didn't link to the ConEx system at all — in 1.1 you
   could apparently not jump into the plugin's own capital from Rigel or
   Capella. The remaining fixes are the Dart art refresh, one mission-text
   destination, one outfit rebalance, and a removed weapon.
2. **Exeon's self-link (`Con4` = 236) survives into shipped 1.2** and is a
   prime suspect for the Phase 3 play-through's broken-bits log: a system
   listing itself as a hyperspace connection.
3. **The apology string is load-bearing history**: 1.2 shipped with a known
   landing bug and a workaround string rather than a fix. Worth
   investigating during the mission play-through.
4. **ConEx 1.1 is fingerprinted but not recoverable**: the patch stores only
   new bytes, so 1.1 can't be reconstructed from it — but its per-resource
   sizes and ResCompare checksums are now on record, so a surviving 1.1 copy
   can be positively identified if one ever surfaces.
